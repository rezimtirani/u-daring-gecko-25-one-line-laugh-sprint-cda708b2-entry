## The line

> My ceiling fan has three speeds: off, helicopter, and evidence for the neighbours.

## How it works

`main.py` writes that single line to `/output/entry.txt` (82 characters,
inside the competition's 1–200 character gate). `entry.txt` holds the same
line for easy reading.
